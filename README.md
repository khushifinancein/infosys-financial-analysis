# Infosys Ltd — Financial Analysis Project

**Analyst:** Khushi Prajapati
**Date:** September 2026

## Project Overview
End-to-end financial analysis of Infosys Ltd (NSE: INFY) built on 10 years of publicly available data from Screener.in and annual reports.

## What This Project Contains
- **Historical Financial Statements** — Income Statement, Balance Sheet, Cash Flow (FY17–FY26)
- **Ratio Analysis** — All 6 categories: Profitability, Efficiency, Liquidity, Solvency, Valuation, Capital Allocation
- **Revenue Forecasting** — Using Arithmetic Mean, Geometric Mean, and Linear Regression (FY27–FY31)
- **DCF Valuation Framework** — FCFF, WACC, Terminal Value concepts applied
- **Equity Research Note** — Formal Buy/Hold/Sell recommendation with investment thesis and risk analysis

## Tools Used
- Microsoft Excel
- Screener.in
- Valuation School Financial Modelling Framework

## Key Findings
- Infosys ROCE improved from 24.5% (FY17) to 36.6% (FY26) — consistently above cost of capital
- Negative Cash Conversion Cycle averaging -24 days — exceptional working capital efficiency
- Revenue CAGR of ~11.42% over the decade with recent moderation
- **Recommendation: HOLD** at CMP ₹1,087 | Target re-rating at ~20x P/E
